# 💳 Transaction System

A simple **Transaction Management System** developed using **HTML, CSS, and JavaScript**. The project provides a step-by-step transaction process with a lock screen, receiver validation, verification, payment method selection, and bill generation.

## ✨ Features

* 🔐 **Lock Screen** – Provides an initial security screen before accessing the transaction system.
* 👤 **Receiver Validation** – Checks whether the person receiving the money is valid.
* ✅ **Receiver Verification** – Verifies the receiver details before proceeding.
* 💰 **Payment Method Selection** – Allows users to choose a suitable payment method.
* 💸 **Money Transfer** – Allows users to enter the amount and complete the transaction.
* 🧾 **Bill Generation** – Generates and displays a bill/receipt after a successful transaction.
* 📜 **Transaction Details** – Displays important details of the completed transaction.
* 🎨 **User-Friendly Interface** – Simple and easy-to-use interface.

## 🔄 Transaction Flow

```text
🔐 Lock Screen
      ↓
👤 Enter Receiver Details
      ↓
🔍 Check Receiver Validity
      ↓
✅ Receiver Verification
      ↓
💵 Enter Amount
      ↓
💳 Choose Payment Method
      ↓
✔️ Confirm Transaction
      ↓
💸 Transaction Successful
      ↓
🧾 Generate Bill / Receipt
```

## 🎯 Project Objective

The objective of this project is to create a simple and user-friendly transaction system with a secure access screen and a structured payment process. The system validates and verifies the receiver before allowing the transaction and generates a bill after successful completion.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Unlock the system using the lock screen.
5. Enter the receiver details.
6. Complete receiver verification.
7. Enter the transaction amount.
8. Select a payment method.
9. Confirm the transaction.
10. View the generated bill/receipt.
